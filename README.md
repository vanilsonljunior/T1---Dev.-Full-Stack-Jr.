# Atividade 4 e 5 - Landing Page Corporativa (T1/2026)

Este projeto consiste em uma Landing Page moderna desenvolvida para a **Gestta Advisory**, uma consultoria especializada em Estratégia Híbrida e Inteligência de Dados. O site foi construído utilizando tecnologias web fundamentais (HTML, CSS e JavaScript) como parte dos requisitos práticos da **Codifica Edu**.

---

## 🚀 Funcionalidades Principais

*   **Design Responsivo:** Interface otimizada para visualização em computadores, tablets e smartphones.
*   **Chamada para Ação (CTA):** Botão estratégico "Inscreva-se na Mentoria" com rolagem suave até a área de conversão.
*   **Consumo de API Externa (ViaCep):** Preenchimento automático e assíncrono dos campos de Cidade e Estado assim que o usuário insere um CEP válido no formulário.
*   **Formulário de Contato Inteligente:** Captura estruturada de informações (Nome, E-mail, CEP e Mensagem) com feedback instantâneo ao usuário.

---

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização moderna com layout baseado em Flexbox, paleta de cores corporativa (grafite e esmeralda) e fontes importadas do Google Fonts.
*   **JavaScript (ES6+):** Manipulação de DOM, tratamento de eventos e consumo assíncrono de API via `fetch()`.

---

## 🌿 Estrutura de Versionamento (Git)

O projeto seguiu o fluxo sugerido de boas práticas de ramificação:
*   `main` (ou `Principal`): Branch contendo a versão estável e finalizada do código.
*   `develop`: Branch utilizada para o desenvolvimento ativo, criação de arquivos e testes antes da fusão final.
